# Work To Do Deploy

Team-shared work-to-do product planning and deployment workspace.

## Current Contents

- `PRD.md`: Product requirements document for the team Work To Do app.

## Planned Direction

- User authentication with separate ID/password per user.
- Database-backed personal and team tasks.
- Role-based permissions for members, managers, and admins.
- Netlify-first deployment, with external Auth/DB such as Supabase.
